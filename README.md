# Advanced Calculator

A simple calculator built using HTML, CSS, and JavaScript.

## Features

- Addition (+)
- Subtraction (-)
- Multiplication (×)
- Division (÷)
- Percentage (%)
- Power (^)
- Square Root (√)
- Parentheses
- Decimal Numbers
- Backspace (⌫)
- Clear Screen (C)

## Project Structure



## How to Run

1. Download or clone the project.
2. Open `index.html` in any modern web browser.
3. Start calculating.
